# Personal Portfolio — Template

This is a minimal, responsive personal portfolio template built with HTML, Tailwind CSS (CDN), and vanilla JavaScript.

Quick start

1. Open `index.html` in your browser (no build step required).

2. Replace placeholder copy, images, and links:
   - Update your name, bio, and sections in `index.html`.
   - Replace `assets/resume.pdf` with your resume (or update the link).
   - Update contact `mailto:` address in `index.html` and `script.js`.

Customization

- Tailwind is loaded via CDN — if you prefer a build step (PostCSS, Tailwind CLI), replace CDN usage with a proper toolchain.
- Modify colors and spacing in `styles.css` for custom accents.

Files

- `index.html` — main markup and content
- `styles.css` — small custom styles and utilities
- `script.js` — theme toggle, mobile menu, form handling
